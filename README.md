# 和想館 メインサイト 静的デモ（非公式・自主制作）

着物店「和想館」をモデルに、小倉英嗣が応募用に制作した **非公式の自主制作デモ** です。
和想館の公式サイトではありません。予約・購入・お問い合わせ・検索・送信は動作しない、見た目だけのモックです。

公開URL：https://ogura-hidetsugu.github.io/wasoukan-main-demo/

## 構成

- HTML・CSS・JavaScript のみ（PHP・WordPress・データベースは使っていません）
- `index.html` … トップページ
- `assets/css/style.css` … デザイン（色・文字サイズは AI Bento Studio の編集結果に合わせています）
- `assets/js/main.js` … ヒーローの写真切り替え、スクロール表示、絞り込みの表示確認、スマホ用メニュー
- `assets/img/` … 画像（WebP）

## ヒーローの動き

- LP.psd と同じ扇形ロゴ（`hero-mask.png`）で写真を切り抜き、CSS の `mask-image` で表示
- 4枚の写真を 6 秒ごとに、2.4 秒かけて重ねながら切り替え（じわっとしたクロスフェード）
- 表示中の写真はゆっくり 1.06 倍まで拡大
- 読み込み直後は、写真 → 文章の順に段階的に表示
- OS の「視差効果を減らす／アニメーションを減らす」設定が有効な場合は、切り替えを止めて1枚目のみ表示

切り替えの速さは `assets/js/main.js` の `INTERVAL`（表示時間）と、`style.css` の `.hero__slide` の `transition`（フェード時間）で調整できます。
